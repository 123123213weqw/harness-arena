在当前目录 `calc.py` 实现整数表达式求值函数 `evaluate(expr) -> int`:

- 字面量:十进制非负整数(无前导 `+`);运算符:`+ - * // %`(语义同 Python,整除与取模为 floor);括号 `()`;一元负号可出现在表达式开头、`(` 之后或二元运算符之后(如 `12*-3 == -36`、`3--2 == 5`);
- 空白字符任意位置允许,求值时忽略;
- 优先级与结合性同 Python;
- 非法输入(空串、括号不配对、`2+`、`*3`、`1 2`、`()`、含非法字符等)抛 `ValueError`;除零按 Python 原生抛 `ZeroDivisionError`。

保持签名不变。完成后用随机表达式与 `eval` 对拍自测再结束。
