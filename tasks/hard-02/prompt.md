实现当前目录 `walks.py` 的 `count_walks(n, edges, L, s, t, mod) -> int`:有 n 个节点(编号 0..n-1)的有向图,edges 是有向边 (u, v) 的列表(**允许重边与自环,重边各计一条**),求从 s 出发恰好走 L 步到达 t 的游走(walk)条数,对素数 mod 取模。

约束:n ≤ 50,0 ≤ L ≤ 10^9,mod 为素数(如 998244353)。**L 可达 10^9,逐步 DP 会超时,必须矩阵快速幂**(O(n^3 log L))。L=0 时:仅当 s == t 时为 1,否则 0。

完成后与小规模暴力(逐步转移)对拍自测再结束。
