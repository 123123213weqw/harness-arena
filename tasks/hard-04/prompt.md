石堆博弈(Grundy's game 规则):桌上有若干堆石子。双方轮流行动,每次必须**选一堆多于 1 颗的石子,把它拆成两堆大小不同**的正整数堆(如 5 → 2+3 可以,4 → 2+2 不行,堆为 1 或 2 时无法行动)。无法行动者输,双方都最优策略。

实现当前目录 `game.py` 的 `winner(piles) -> str`:piles 为各堆石子数列表,先手必胜返回 `"First"`,否则 `"Second"`。

约束:1 ≤ 堆数 ≤ 10^5,1 ≤ 每堆 ≤ 2000。**必须 Sprague-Grundy:预计算单堆 Grundy 数后异或**——对整局做博弈树搜索必然超时。空列表返回 `"Second"`。完成后与小规模博弈树穷举对拍自测再结束。
