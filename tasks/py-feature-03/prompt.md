在当前目录 `lrucache.py` 实现 `LRUCache` 类(当前为占位抛错):

- `LRUCache(capacity)`:`capacity` 为正整数,否则抛 `ValueError`;
- `get(key) -> value`:命中返回值并把该键标记为最近使用;未命中返回 `-1`(不抛错);
- `put(key, value)`:键已存在则更新值并标记为最近使用;不存在则插入,若超容量则**逐出最久未使用**的键;
- `get`/`put` 都要求 O(1) 平均复杂度(隐藏测试含 30 万次操作的性能门槛,朴素线性扫描会超时);
- 键值为任意可哈希对象,int 值可能为 0(不要用 0 当哨兵)。
