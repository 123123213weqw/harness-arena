实现当前目录 `mdrender.py` 的 `render(text) -> str`:把 markdown 子集渲染为 HTML。块级规则(按行扫描,空行分块):

1. `# `/`## `/`### ` 开头 → `<h1>/<h2>/<h3>`(仅这三级);
2. ``` 围栏:以 ``` 单独成行开始与结束,内部所有行原样(不解析行内标记)并入 `<pre><code>`+`\n`+`</code></pre>`;围栏内空行保留;
3. `- ` 开头的连续行 → `<ul>`,每行一个 `<li>`;
4. 其余连续非空行 → `<p>`,行间以单个空格连接;
5. 块之间以单个 `\n` 连接(无空行)。

行内规则(段落与 li 内,从左到右、不嵌套、不成对标记原样保留):

- `` `c` `` → `<code>c</code>`(c 不含反引号)
- `**b**` → `<strong>b</strong>`
- `*i*` → `<em>i</em>`
- 同一优先级按出现顺序处理;标记内容可为空串。
