实现当前目录 `absent.py` 的 `smallest_absent(s) -> str`:给定只含小写字母的字符串 s,求**没有在 s 中作为连续子串出现**的字符串中,(1) 长度最短、(2) 同长度中字典序最小**的那个**,返回它。

例如 `"a"` → `"b"`(b 是长度 1 里字典序最小的缺失);`"abcdefghijklmnopqrstuvwxyz"` → `"aa"`;`"aaa"` → `"b"`。

约束:1 ≤ |s| ≤ 2×10^5。**注意 26^4 = 456976 > 2×10^5,答案长度必然 ≤ 4**——但逐个候选做 `cand in s` 的朴素检查在长串上会超时,应按长度对 s 的子串建集合再按字典序扫描候选。完成后与小串暴力对拍自测再结束。
