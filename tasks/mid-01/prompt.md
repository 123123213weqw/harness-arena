实现当前目录 `iniparse.py` 的 `parse(text) -> dict`:解析一种 INI 方言,返回嵌套 dict(节名 → 键值 dict)。规则:

1. **节头**:`[name]` 单独成行,`name` 非空且不含 `]`;首次出现的节建立空 dict;**重复节头合并**(后值覆盖前值);
2. **键值**:`key = value`,key 无空白;value 为整行 `=` 右侧**去掉首尾各一个空格**的结果(仅一个,不 strip 其他空白);`=` 前必须恰好一个空格、后必须恰好一个空格,否则该行非法;
3. **续行**:缩进(以空格开头)的行把 ` 去续行符后的内容` 追加到上一键(以单个空格连接);续行不能出现在任何键之前;
4. **注释**:`;` 或 `#` 开头(无缩进)的行忽略;**行内注释不剥除**(`a = 1 ; x` 的值是 `1 ; x`);
5. **转义**:`\n` 在值里替换为换行、`\\` 替换为反斜杠(其他 `\x` 原样保留);
6. 节头/键值/续行之外的任何行抛 `ValueError("bad line: <整行>")`;空行忽略;任何键必须在某个节内(节前出现键值抛 ValueError)。
