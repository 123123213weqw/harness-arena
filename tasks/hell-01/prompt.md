实现当前目录 `interp.py` 的 `run(program) -> list[str]`:解释执行 MINI 语言程序,返回所有 `print` 输出的字符串列表。

## 语言规范

- 程序是语句列表(每元素一行);变量为小写字母标识符,**仅存整数**;未定义变量被读取视为运行时错误;
- 语句三种:
  - 赋值:`x = <expr>`
  - 输出:`print <expr>`(输出十进制整数,负数带 `-`)
  - 条件/循环:`if <expr>: <语句; 语句; ...>` 与 `while <expr>: <语句; 语句; ...>`——体为同一行内分号分隔的一条或多条语句(不能嵌套 if/while);
- 表达式(优先级从低到高):比较 `== != < <= > >=`(结果 1/0,不链式)、加减 `+ -`、乘除模 `* / %`(除法与取模为 **floor 语义,同 Python**,即 `-7 / 2 == -4`、`-7 % 3 == 2`)、一元负号、括号、整数与变量字面量;
- `if`/`while` 以条件值**非 0 为真**;
- 执行上限:**10^6 条语句**,超出抛 `RuntimeError`(防死循环);
- 运行时错误(除零、读未定义变量、语法错误)抛 `ValueError`;抛错时**已产生的输出保留**由调用方持有——即 `run` 直接向上抛异常,不返回部分结果;
- 语法错误在任何语句上都抛 `ValueError`(包括格式不对的行)。

隐藏测试为 20 个左右完整程序,覆盖循环求和/阶乘/斐波那契、嵌套分号体、运算优先级、负数 floor 除、比较短路陷阱、运行时错误等。完成后自测再结束。
